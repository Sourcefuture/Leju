# Kuavo-5 比赛桌面基础场景检查

场景采用此前同一份官方Kuavo-5.2模型 `biped_s52`，将桌面和物料调整为提供的比赛尺寸。本阶段供检查尺寸、布局、相机视角和标定点；尚未执行视觉标定求解、手臂到点或抓取。

## 查看场景

```bash
cd /home/source/LeTools-Learning
bash tools/kuavo_tabletop.sh gui
```

俯视布局：

```bash
bash tools/kuavo_tabletop.sh gui --camera weighing_top
```

自由调整观察视角：

```bash
bash tools/kuavo_tabletop.sh gui --camera ''
```

机器人头部画面：

```bash
bash tools/kuavo_tabletop.sh camera --camera head --live
```

GUI中的五个红色标记为四角和中心。生成的预览图按已知三维坐标投影附上A至E标签，标签不表示视觉检测成功；GUI中的标记本身没有印刷文字。电子秤居中后覆盖中心E点，物料箱也可能遮挡角点，标定时需要暂时移开相应物料。

## 尺寸与暂定配置

| 项目 | 场景配置 |
|---|---|
| 机器人 | 原有Kuavo-5.2，双臂初始放下 |
| 桌面 | 120×60 cm，橡木色，白色桌腿，长边朝向机器人 |
| 桌面工作高度 | 暂定0.76 m，可调 |
| 机器人原点到近桌沿 | 暂定0.22 m，可调；不是手臂到桌沿的距离 |
| 桌布 | 香槟色，180 cm沿桌面长边、140 cm沿短边 |
| 物料箱 | 外尺寸400×300×230 mm，桌面右侧；颜色和10 mm壁厚暂定 |
| 袋捆 | 白、绿、黑各一捆，200×300 mm，桌面左侧从近到远排列；每捆厚度暂定12 mm，用3层示意 |
| 填充物 | 用12个静态颗粒表示2～10 cm粒径范围，放在物料箱内 |
| 电子秤 | 230 mm沿桌面长边、170 mm沿短边、高20 mm，桌面中心 |

桌布用台面和四块下垂侧片表示，没有软体布料、皱褶和角落折叠仿真。填充物的总供应量5斤（2.5 kg）、秤的5 kg量程和0.1 g显示分度写入配置说明；当前场景没有模拟这些物料的称重或电子秤精度。

袋捆、箱子和秤的位置是待确认布局，不是比赛指定的固定位置。实际抓取点和手臂可达范围留待后续验证。

## 桌面坐标

原点在机器人视角的近侧左角，X向右，Y远离机器人，Z向上。单位米。

| 标记 | 位置 | 桌面坐标 |
|---|---|---|
| A | 近左角 | `[0,0,0]` |
| B | 近右角 | `[1.2,0,0]` |
| C | 远右角 | `[1.2,0.6,0]` |
| D | 远左角 | `[0,0.6,0]` |
| E | 中心 | `[0.6,0.3,0]` |

仿真世界系中，机器人朝+X，机器人左侧为+Y。配置文件给出 `T_world_table`，用于把桌面坐标转成世界坐标；它是生成场景时定义的真值，不是由视觉或手臂标定测量得到的结果。

## 调整桌高和位置

例如将工作高度改为0.75 m，近桌沿距机器人原点改为0.18 m：

```bash
bash tools/kuavo_tabletop.sh build --table-height 0.75 --table-gap 0.18
```

重新生成后，关闭原窗口并重新打开GUI。重建会更新所有桌面物料、标记和预览；不会改变此前称重场景的文件。

## 检查文件

```text
outputs/kuavo_sim/tabletop_calibration/
├── scene.xml          # 完整Kuavo-5.2基础场景
├── scene_info.json    # 尺寸、假设、摆放、五点坐标和世界变换
├── overview.png       # 机器人与桌面全景
├── top.png            # 仿真俯视画面
├── head.png           # 机器人头部相机画面
└── layout.png         # 按尺寸绘制的桌面平面图
```

重新生成预览：

```bash
bash tools/kuavo_tabletop.sh render
```

使用独立手臂状态目录 `outputs/robot_control/kuavo5_tabletop`，与此前称重测试分开。

建议先检查长边朝向、桌高、机器人与桌子的间距、箱子与秤的位置，以及头部相机是否能看到所需工作区。确认后再实现图像与桌面标定、手臂标定和IK求解。
